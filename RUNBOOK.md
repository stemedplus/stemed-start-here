# Runbook: Start Here (Why STEMEd+?)

This site uses the shared STEMEd+ look. For how every board works and the common fixes, see the [stemedplus-theme runbook](https://github.com/stemedplus/stemedplus-theme/blob/main/RUNBOOK.md).

| | |
|---|---|
| **Site** | stemedplus.github.io/stemed-start-here (also `/open/`, Open by Design) |
| **Repository** | stemedplus/stemed-start-here |
| **Updates** | On push, daily at 10:17 UTC (to pick up theme changes and the member count), and by hand (`publish.yml`) |
| **Content** | Hand-written HTML in `site/`; images and logos live here too. Each run also refreshes `site/members.json`, the STEMEd+ member count shown on the stemedplus.org homepage. |

Edit the page in `site/` and push. The STEMEd+ logo used by the menu bar on every site is served from here, so keep `site/stemedplus-commons-logo.png` and `-white.png` in place.
